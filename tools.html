PYTHON / VIDEO PIPELINE

VideoTool 视频处理工具

连接素材任务、预览、区域处理与文件管理。

实现与交付

  • 基于 yt-dlp 解析媒体信息，选择视频画质或音频。
  • 用后台任务与进度回调管理耗时处理。
  • 用 OpenCV 提供候选区域，支持 Canvas 手动框选。
  • 调用 ffmpeg / OpenCV 处理视频区域并保留音轨。
