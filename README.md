## 🖼 作品图说明

作品图片按 `分类-序号.webp` 命名，缩略图加 `-t` 后缀。

| 分类 | 前缀 | 数量 |
|---|---|---|
| 品牌设计 | `brand-` | 6 |
| 海报设计 | `poster-` | 6 |
| 标志设计 | `logo-` | 7 |
| UI 设计 | `ui-` | 7 |
| 键帽设计 | `keycap-` | 7 |
| 其他设计 | `other-` | 5 |

**要增删作品**：把新图放进 `images/`（建议 1560px 宽的 WebP），
然后编辑 `js/main.js` 顶部的 `CATS` 数组里的数量即可。

```js
const CATS = [
  ['brand',  '品牌设计', 6],   // 改成实际数量
  ...
];
```


## 🚀 如何打开

双击 `index.html` 即可在浏览器中直接预览，无需安装任何环境。

## ✏️ 如何个性化修改

### 1. 基本信息（名字、介绍、联系方式）
网站已按简历更新为「徐昊」的真实信息（姓名、学校、联系方式、项目经历）。
如需再次修改，直接搜索 `index.html` 中的「徐昊」或对应段落即可。

### 2. 替换 / 新增作品图片
作品图片由 `js/main.js` 自动渲染，图片放在 `images/` 目录。
只需按命名规则放图，再改 `CATS` 数组的数量，无需改 HTML。

### 3. 调整配色
打开 `css/style.css` 顶部 `:root` 变量区域，修改
`--accent-1 / --accent-2 / --accent-3` 三个颜色即可全局换肤。

### 4. 联系表单
当前表单提交后调用系统邮件客户端（mailto），已配置为你的 QQ 邮箱 `2327149251@qq.com`。
如需真实后台，可接入 Formspree / 腾讯云开发等表单服务。

### 5. 添加 / 删除作品
见上面「作品图说明」—— 放图 + 改 `CATS` 数量即可，
分类筛选按钮在 `index.html` 的 `#filterBar` 中，可自行增删。

## ⌨️ 交互说明

- **作品网格**：悬停显示分类与序号，点击打开大图灯箱
- **灯箱**：`←` `→` 切换、`Esc` 关闭、底部缩略图可点击跳转、手机可左右滑动
- **分类筛选**：点击筛选按钮，带作品计数

## 🌐 部署上线（可选）

- **GitHub Pages**：把整个文件夹推送到 GitHub 仓库，Settings → Pages 选择 main 分支即可。
- **Vercel / Netlify**：直接拖拽文件夹上传，自动部署。
- **国内**：Gitee Pages、腾讯云静态网站托管、阿里云 OSS 等。
